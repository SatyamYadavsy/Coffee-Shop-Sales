# Coffee Shop Sales Analysis Dashboard

1. Project Overview

The objective of this project is to analyze retail sales data from a coffee shop and generate actionable insights that can help improve business performance.

The analysis focuses on sales trends, customer purchasing activity, store performance, product performance, and peak sales periods.

2. Business Questions

This project explores questions such as:

- How do sales vary by day of the week and hour of the day?
- Are there peak times for sales activity?
- What is the total sales revenue for each month?
- How do sales vary across different store locations?
- What is the average price/order per person?
- Which products perform best in terms of quantity and revenue?
- How do sales vary by product category and product type?

3. Dataset

The workbook contains a Transactions sheet with 149,116 transactions covering January 1, 2023 to June 30, 2023.

Key fields include:

- Transaction ID
- Transaction Date
- Transaction Time
- Transaction Quantity
- Store ID / Store Location
- Product ID
- Unit Price
- Product Category
- Product Type
- Product Detail
- Size
- Total Bill
- Month
- Day of Week
- Hour

The analysis covers 3 store locations and 9 product categories.

4. Data Cleaning & Preparation

Before performing the analysis, the raw transaction data was cleaned and prepared to ensure consistency and accuracy.

The data preparation process included:

- Checking for missing and inconsistent values
- Removing duplicate records where applicable
- Verifying data types and formatting
- Standardizing relevant fields
- Creating/validating fields required for analysis
- Preparing the cleaned dataset for further analysis

After the data was cleaned and prepared, Microsoft Excel was used to perform the analysis and build the interactive dashboard.

5. Tools Used

- Microsoft Excel
- Excel Tables
- Formulas and calculated fields
- Pivot Tables
- Pivot Charts
- Dashboard design
- Data aggregation and analysis

6. Dashboard

The dashboard was created in Microsoft Excel to provide a visual summary of coffee shop sales performance.

7. Key KPIs

- Total Sales: $698,812.33
- Total Transactions: 149,116
- Total Items Sold: 214,470
- Average Order Value: $4.69
- Average Items per Order: 1.44

8. Analysis Areas

The dashboard analyzes:

- Monthly sales performance
- Sales by store location
- Sales by product category
- Product-level sales performance
- Transaction activity by day of week
- Transaction activity by hour
- Order and quantity patterns

9. Key Insights

Based on the analysis:

1. June recorded the highest monthly sales, with approximately $166.49K in revenue.
2. Coffee was the highest-revenue product category, generating approximately $269.95K.
3. Hell's Kitchen generated the highest sales among the three store locations, with approximately $236.51K.
4. Friday had the highest transaction volume among the days of the week.
5. The busiest transaction hour was 10 AM, based on transaction activity.
6. The average order value was approximately $4.69, with an average of 1.44 items per transaction.
